## 0. 导读

缠论形态学的构建路径为：

```
分型 → 笔 → 线段 → 中枢 → 走势类型
```

- 分型是对 K 线的归纳。
- 笔是在分型基础上的进一步归纳。
- 线段是在笔基础上的进一步归纳，目的是提高走势结构稳定性（笔变化过于频繁）。
- 中枢由次级别走势重叠构成，是缠论的核心。
- 走势类型由中枢的数量与方向定义。

## 1. 中枢

### 1.1 中枢的定义

- **中枢**：连续三个次级别走势相重叠的部分，构成本级别的一个中枢。
- **盘整走势**：当前级别、当前走势只有一个中枢，称为盘整走势。
- **趋势走势**：当前级别、当前走势有两个或两个以上同向同级别中枢，称为趋势走势。
  - 中枢方向向上 → 上涨走势；
  - 中枢方向向下 → 下跌走势。
- **级别递归（上行）**：连续三个本级别走势相重叠的部分，构成高一级别的中枢。该过程可一直往上直到年线，也可一直往下直到最低级别（每一笔交易）。

### 1.2 中枢的递归与级别

- 实操中，纠结最低级别没有意义（低级别差价不够手续费、来不及反应）。为分析方便，通常把 **1 分钟当作最低级别，年线当作最高级别**。
- 递归规则：
  1. 1min 级别的线段，是 1min 级别中枢的最小构成元素。
  2. 将 1min 级别中枢组合成上涨、下跌、盘整的走势类型后，将相邻走势组合，连续 3 个 1min 级别走势相重合的部分，构成 **5min 级别的中枢**。
  3. 5min 级别的中枢又可组成 5min 级别的上涨、下跌、盘整走势。
  4. 连续 3 个 5min 级别走势相重合的部分，构成 **30min 级别的中枢**。
  5. 依次递归上去，最终可得年线级别的中枢与走势（年线级别太大，未必有完整的中枢和走势类型）。

### 1.3 最低级别说明

- 打开交易软件分时成交明细，同一时间点汇总的总交易笔数，可视作最低级别的高一级别。
- 连续三个同样报价的成交，即最低级别的中枢。
- 大于等于两个同向的中枢，构成最低级别的趋势。
- 一个中枢，构成最低级别的盘整。
- 将最低级别的盘整、上涨、下跌等走势类型组合，连续三个走势相互重叠的部分，构成高一级别的中枢；高一级别再组合得到高一级别的盘整/上涨/下跌；如此类推。

### 1.4 中枢的区间与构成要素

- 中枢由"连续三个次级别走势相重叠的部分"构成，因此中枢区间 = 这三段次级别走势的**重叠区间**。
  - 对三段走势而言：中枢上界 = 三段走势低点的最大值；中枢下界 = 三段走势高点的最小值；当上界 ≥ 下界时，重叠区间存在，中枢成立。
- 中枢可以随时完成，也可以继续在中枢范围内震荡（见 2.2 延伸）。

## 2. 中枢的形态演变

### 2.1 中枢的新生

- **定义**：在原中枢的上方或下方产生新的同向中枢，称为中枢的新生。
- 中枢的新生必定伴随着原中枢的结束。
- **原中枢结束的标志**：原中枢产生第三类买卖点（3 买/3 卖）。
- 典型过程（以上涨为例）：第一个中枢确认 3 买 → 在上方形成第二个同向同级别中枢 → 确认上涨趋势。从中枢 1 到中枢 2 的过程即中枢新生。

### 2.2 中枢的延伸与震荡

- 连续三个次级别走势相重合的部分构成本级别中枢后，该中枢可以随时完成，也可继续在中枢范围内震荡，走出第四个、第五个、第六个……次级别走势。
- 这些后续次级别走势与前三个次级别走势确定的中枢范围都有重合区间，称为**中枢的延伸**。
- 围绕中枢的上下波动，称为**中枢的震荡**。
- 示例：1-2、2-3、3-4 三段构成本级别中枢；其后的 4-5、5-6、6-7、7-8 均属于 1-4 这个中枢的延伸。

### 2.3 中枢升级之一：中枢扩展

- **定义**：三个相邻且有重合区间的次级别走势确认本级别中枢后，在中枢范围内不断延伸出新的次级别走势，且延伸出的次级别走势都有一部分与中枢重合。
- **关键数值判定**：
  - 在次级别总数**不超过 9 个**时（含最初确定中枢的 3 个），仍为中枢的**延伸与震荡**。
  - 当次级别**累计达到 9 个**时，每三个相邻的次级别可组成一个本级别中枢，从而得到相邻的三个本级别中枢（即三个本级别盘整走势）。
- 这三个本级别盘整走势有重合区间，该重合区间构成**高一级别的中枢**。此时原中枢由本级别升级为高一级别中枢。
- **结论**：扩展必定发生中枢升级。
- 示例：1-2、2-3、3-4 构成本级别中枢；其后 4-5、5-6、6-7、7-8、8-9、9-10 共延伸 6 段；加上形成中枢的 3 段共 **9 段**。每 3 段构成一个本级别中枢（三个蓝色框），三个本级别中枢组合形成高级别中枢（红框）。即 1-10 组成的中枢比 1-4 的中枢高一级别。

### 2.4 中枢升级之二：中枢扩张

- **定义**：在当前级别已经完成**两个或以上同向中枢**的情况下，围绕后一个中枢的震荡与围绕前一个中枢的震荡区间发生重合，称为中枢的扩张。
- 比喻：两个中枢相当于两颗独立恒星；围绕恒星运动的行星发生碰撞后，两颗恒星及其行星融合为一个更大的恒星体系。
- **结论**：本级别中枢的扩张必然导致中枢升级。
- 示例：1-4 构成第一个本级别中枢；6 为第一个中枢的 3 买；7-10 构成第二个本级别中枢；其后 11-12 的走势**跌破 1-4 中枢震荡的最高点（即 3 点）**；围绕两个中枢的震荡 2-3 与 11-12 发生重合 → 中枢升级，1-12 构成高级别中枢，中枢范围为 **3-12**。

### 2.5 扩展与扩张的区别

扩展与扩张都能使中枢升级，但本质不同：

| 项目 | 扩展 | 扩张 |
|---|---|---|
| 原中枢状态 | 没有结束 | 已经结束 |
| 升级原因 | 围绕原中枢震荡延伸 | 围绕两个中枢的次级别波动重合 |
| 是否有 3 买 | 没有 | 有 |
| 触发阈值 | 次级别累计达 9 段 | 两个同向中枢的震荡区间重合 |

## 3. 走势类型

### 3.1 完全分类原则

- 任何级别的任何走势，都能且只能分解为**趋势**与**盘整**两类；趋势又分为**上涨**与**下跌**两类。绝对没有第四种走势类型。
- 形态学路径（分型→笔→线段→中枢→走势类型）最终为走势类型服务。
- 缠论三类买卖点及其衍生的"类三类买卖点"，全部出现在**某级别相邻走势类型转换的转折点位置**。

### 3.2 三种基本走势类型的定义（由中枢数量判定）

- **上涨走势**：当前级别自低点开始，**至少有两个向上的中枢**，则自低点开始的走势构成上涨走势。
- **下跌走势**：自高点后，**至少有两个向下的中枢**，则自高点开始的走势构成下跌走势。
- **盘整走势**：当前级别走势**有且只有一个中枢**，则构成盘整走势。
- 关键区别：趋势（上涨/下跌）与盘整的根本差异在于所包含的**同向中枢数量**——趋势至少有两个同向中枢，盘整有且只有一个中枢。所有定义均在"当前级别"下成立。

### 3.3 走势终完美

- 任何走势类型在图形上最终都要完成。
- 已经确认的上涨趋势，在没有出现**背驰**之前不会结束。
- 任何走势不会走到一半戛然而止。
- 任何走势类型一旦开始必将结束，结束后必将**转换为其他走势类型**：
  - 上涨走势结束 → 转换为盘整或下跌
  - 下跌走势结束 → 转换为盘整或上涨
  - 盘整走势结束 → 转换为上涨或下跌
- 走势不可预测，但可以**完全分类**。"走势类型一旦开始必将结束、结束后必将转换为其他走势类型"是预判后市唯一可依靠的依据。

### 3.4 六种走势组合（完全分类）

上涨、下跌、盘整三种基本走势，按完全分类有六种组合：

1. **陷阱式**
   - 上涨 + 下跌
   - 下跌 + 上涨
2. **反转式**
   - 上涨 + 盘整 + 下跌
   - 下跌 + 盘整 + 上涨
3. **中继式**
   - 上涨 + 盘整 + 上涨
   - 下跌 + 盘整 + 下跌

### 3.5 有买入价值的走势组合

站在股票不可做空的角度，六种组合中：

- **有买入价值（3 种）**：
  1. 下跌 + 上涨
  2. 下跌 + 盘整 + 上涨
  3. 上涨 + 盘整 + 上涨
- **没有买入价值（3 种）**：
  1. 上涨 + 下跌
  2. 上涨 + 盘整 + 下跌
  3. 下跌 + 盘整 + 下跌

明确有买入价值的组合后，下一步即**确定组合中走势是否开始与结束**。例如"下跌 + 上涨"：一旦判断下跌趋势结束、上涨趋势开始，其转换点即为买点。

## 4. 背驰

### 4.1 背驰的定义与前提

- **背驰**：在趋势或盘整走势中，当前一段走势的力度小于同方向前一段走势的力度，形成力度衰减，预示走势可能发生转折。
- 背驰是缠论动力学最核心的内容，是判断走势转折的核心技术依据。
- **背驰成立的前提**：必须有中枢的存在，背驰只能发生在有中枢的走势中；没有中枢就不谈背驰。

### 4.2 力度的衡量

力度主要通过两种方式衡量：

1. **MACD 指标**：通过 MACD 黄白线（DIF/DEA）的位置、红柱/绿柱面积的对比判断力度。
2. **笔的长度/高度**：进中枢笔与出中枢笔在价格空间上的幅度对比。

要点：

- 力度比较必须是**同方向**的两段走势之间进行。
- 比较必须以**已经完成的笔/段**为对象，未完成的笔不能用来判定背驰。

### 4.3 趋势背驰

- **趋势背驰**：在趋势走势（含两个或两个以上同级别中枢）中，离开最后一个中枢的那一段（出中枢笔/段）的力度，小于进入该中枢的那一段（进中枢笔/段）的力度。
- **成立必要条件**：
  1. 走势必须是**趋势**（至少含两个同级别中枢）。
  2. **必须突破（离开）最后一个中枢**——出中枢笔必须真正离开中枢区间，否则不构成趋势背驰的判定前提。
  3. 出中枢笔的力度 < 进中枢笔的力度。
- 趋势背驰一旦成立，预示该趋势可能结束，至少出现一个反向的同级别走势类型。

### 4.4 盘整背驰

- **盘整背驰**：在盘整走势（只有一个中枢）中，离开中枢的那一段的力度，小于进入中枢的那一段的力度。
- **成立必要条件**：
  1. 走势为**盘整**（只有一个中枢）。
  2. 离开中枢的笔/段必须**突破中枢区间**（否则只是中枢内震荡，不构成盘整背驰）。
  3. 出中枢段力度 < 进中枢段力度。
- 盘整背驰的结果：通常回到中枢内（中枢级别扩展或震荡延续），不一定发生趋势反转。

### 4.5 进中枢笔与出中枢笔

- **进中枢笔（进入笔）**：形成（或进入）中枢的那一笔，方向与中枢构建方向一致。
- **出中枢笔（离开笔）**：离开中枢的那一笔，方向与进中枢笔同向。
- 进中枢笔与出中枢笔必须**同方向**，才能进行力度比较。
- 必须是**离开中枢**的笔才叫出中枢笔，未离开中枢区间的不算。

### 4.6 背驰段

- **背驰段**：在趋势/盘整中，离开中枢的那一段走势（出中枢笔或由若干笔组成的段），即背驰判断的对象，称为背驰段。
- 背驰段的级别必须与进中枢段级别一致，才有比较意义。
- 若背驰段内部又形成中枢，则需对该中枢进行同样的力度分析，逐级判断背驰（见第 6 章区间套）。

### 4.7 MACD 判定方法

- **MACD 黄白线（DIF、DEA）**：反映走势整体力度方向与强弱。
- **MACD 红柱/绿柱面积**：反映当前走势段的瞬时力度。上涨看红柱面积，下跌看绿柱面积。
- **面积背驰**：仅以 MACD 红/绿柱面积作为力度衡量依据的背驰判定。是最常用的方式。

判定条件：

- **面积背驰**：出中枢段对应的 MACD 柱面积 < 进中枢段对应的 MACD 柱面积。
- **黄白线背驰**：出中枢段对应的 MACD 黄白线高度/低度弱于进中枢段。
- 两者一致时背驰更可靠；不一致时以面积为主，黄白线作为辅助确认。
- MACD 面积的取值区间（起止 K 线）需严格对应该笔/段的起止点，避免取错区间导致面积误算。

### 4.8 背驰判定流程（算法步骤）

1. 判断当前走势类型：是否为趋势或盘整，是否含有中枢。
2. 找出中枢，确定中枢区间（上界/下界）。
3. 确定进中枢笔（进入中枢的那一笔，方向与走势方向一致）。
4. 确定出中枢笔（离开中枢的那一笔，方向与进中枢笔同向，且必须突破中枢区间）。
5. 取进中枢笔对应区间的 MACD：红柱面积（上涨）或绿柱面积（下跌）；该段 MACD 黄白线高低位置。
6. 取出中枢笔对应区间的 MACD：红柱面积（上涨）或绿柱面积（下跌）；该段 MACD 黄白线高低位置。
7. 比较两者：
   - 出中枢笔柱面积 < 进中枢笔柱面积 → 面积背驰；
   - 出中枢笔黄白线弱于进中枢笔 → 黄白线背驰。
8. 若面积背驰成立（黄白线背驰同步则更可靠），判定为背驰。
9. 区分背驰类型：
   - 走势含 ≥2 个同级别中枢 → 趋势背驰；
   - 走势仅含 1 个中枢 → 盘整背驰。
10. 给出后续预期：
    - 趋势背驰：预期趋势结束，出现反向同级别走势；
    - 盘整背驰：预期回到中枢内，中枢延续或扩展。

### 4.9 趋势背驰与盘整背驰对比

| 项目 | 趋势背驰 | 盘整背驰 |
|---|---|---|
| 中枢数量 | ≥2 个同级别中枢 | 1 个中枢 |
| 突破要求 | 突破最后一个中枢 | 突破该唯一中枢 |
| 后果 | 趋势可能反转，至少出现反向同级别走势 | 通常回到中枢内，未必反转 |
| 适用结构 | 同级别趋势中 | 同级别盘整中 |

### 4.10 边界条件与易错点

1. 必须先有中枢，再谈背驰：无中枢不背驰。
2. 出中枢笔必须真正突破中枢：未突破中枢区间（仅在中枢内震荡）的笔，不构成背驰判定对象。
3. 比较必须同方向、同级别：反向笔、不同级别的笔不能比较。
4. 未完成的笔不能判定背驰：必须等笔走完（被新笔确认）后才能判定。
5. 盘整背驰 ≠ 趋势背驰：盘整背驰后通常回到中枢内，不一定反转；趋势背驰后通常有反向走势。两者不可混用。
6. 没有形成趋势（无两个同级别中枢）时，不能称为背驰，只能称盘背。
7. MACD 面积与黄白线不一致时，以面积为主，黄白线辅助确认。
8. 背驰段内部含中枢时，需逐级分析，不能用大级别直接套小级别的面积。

## 5. 盘整背驰的演化

### 5.1 标准结构 a+B+c

- 盘整走势中，连接中枢前后的两个走势发生背驰的情况，称为盘整背驰，简称盘背。
- 标准的盘整背驰结构为 **a+B+c** 三段：
  - B 为当前级别的中枢；
  - a、c 为连接中枢 B 前后的两次级别走势；
  - c 段为背驰段。
- a 段和 c 段不一定必须为次级别趋势，可以是次级别盘整。
- **判定条件**：c 段相对于 a 段发生背驰，即：
  - c 段对应的 MACD 柱子面积比 a 段小；或
  - c 段对应的 MACD 黄白线（c 比 a 段）低（远离 0 轴的高度缩小）。
- 盘背只需满足其一即可，两个都满足代表盘背更加强烈。
- 若 c 段相对于 a 段对应的 MACD 红/绿柱面积或黄白线远离 0 轴的高度缩小，则 a+B+c 发生盘整背驰，盘整走势于 c 段高点处结束。

### 5.2 三种演化形态

盘整背驰成立后有三种演化形态，必须穷尽：

#### 形态一：确认 3 买/卖，最终演化为趋势

判定条件：

1. c 段向上突破 B 段中枢上限并创新高；
2. c 段与 a 段发生盘整背驰（MACD 柱面积缩小或黄白线降低）；
3. c 段后的回拉没有跌破 B 段中枢上限，形成当前级别 3 买；
4. 其后在同级别同方向上形成第二个中枢，盘整演化为趋势。

（向下情况对称：c 段向下突破中枢下限并创新低，回拉不回中枢形成 3 卖，演化为下跌趋势。）

#### 形态二：盘背后跌回中枢，继续盘整

判定条件：

1. c 段向上突破 B 段中枢上限并创新高；
2. c 段相对于 a 段发生盘整背驰；
3. c 段后的回跌跌破 B 段中枢上限，重新回到 B 段中枢内；
4. 盘整延续（未形成 3 买）。

#### 形态三：盘背不创新高，必有回跌

判定条件：

1. c 段未突破 B 段中枢上限（即未创新高）；
2. c 段相对于 a 段发生盘整背驰；
3. 其后必有回跌，且一般幅度较大。

注意：此处 c 段之前中枢 B 已成立（即 c 段之前已有三段走势重叠确认中枢 B）。

实战要点：一旦出现形态三，应先减仓出来，等待其后回跌低点再回补。

### 5.3 盘整背驰与大周期第一类买卖点

- 走势是分级别的：同一标的同一时间段，级别越低走势结构越复杂，级别越高走势结构越单一。
- A 股时间短，月线及以上级别往往连一个标准中枢的盘整都难以形成（无趋势结构，找不到标准第一类买卖点）。
- **结论**：在大周期（月线及以上）无法找到标准第一类买卖点时：
  - **盘整背驰的低点，可以当做大周期的第一类买点处理**；
  - **盘整背驰的高点，可以当做大周期的第一类卖点处理**。
- 月线级别盘背的历史性底部，是最有价值的中长线买点。

## 6. 区间套

### 6.1 走势的自相似性与走势终完美

- 不同标的、不同时间段的走势虽各不相同，却有一样的内在逻辑与一样的完全分类标准，称为**走势的自相似性**。
- 走势的自相似性使任何标的任何级别的走势都能分解成趋势与盘整两类，趋势又分上涨与下跌，绝对没有第四种——即"走势终完美"。
- 走势终完美的两方面：
  1. 任何走势（趋势或盘整）在图形上最终都要完成；
  2. 一旦某种走势完成，就转化为其他类型的走势。

### 6.2 走势可递归

- 任何级别的任何完成了的走势类型，**必然至少含有 1 个中枢**。
- 每个中枢**至少包含 3 段有重合区间的次级别走势**。
- 每个次级别走势又必然至少含有 1 个中枢，每个中枢至少包含 3 段有重合区间的次次级别走势，可无限细分。
- 反之，从最低级别往上一层一层（先低级别再高级别）即为走势的递归。
- 最低级别定义（实战）：把 1 分钟级别定义为最低级别；1 分钟级别的线段作为 1 分钟级别中枢的构成元素；划分 1 分钟级别的中枢、走势类型，再将 1 分钟走势类型相重合的部分划分为 5 分钟级别的中枢，进而划分 5 分钟级别的走势类型；以此类推，逐级递归，最后可划分年线级别的中枢和走势类型。

### 6.3 区间套定理

基于走势终完美与走势可递归两大原理，可用区间套定理精准定位当下的买卖点。

标准模型（以两中枢下跌趋势 a+A+b+B+c 为例）：

- A、B：当前级别两个中枢；
- a、b、c：连接中枢的次级别走势段；
- c 段为最后一段下跌并发生背驰（c 相对于 b 背驰）。

**区间套定位算法（逐级收敛）**：

1. 在当前级别 a+A+b+B+c 下跌走势中，若 c 段相对于 b 段背驰：
   - a+A+b+B+c 构成的下跌趋势结束（c 段底背驰）；
   - **c 段的低点为第一类买点**。
2. 买点的具体位置可在 **c 段走势**中去找：
   - c 段对应到次级别，也会是 `a+A+b+B+c` 的下跌走势，或 `a+A+b` 的盘整走势。
3. 一步步递归下去，最终可在 **1min 级别**上找到最精准的第一类买点。

> 即：用小级别的背驰段，去定位大级别买卖点的精确位置；每往下一个级别，买卖点的定位区间就进一步收敛。

### 6.4 区间套收敛规则

- 每一层的背驰段（c、c1、c2……）对应到次级别仍是同型结构（两中枢下跌 `a+A+b+B+c` 或盘整 `a+A+b`），逐级递归直至 1 分钟级别。
- 各级别背驰点应**完全重合**，重合即构成区间套。
- 背驰判定条件：MACD 绿柱子面积缩小 + 黄白线高度缩小，两者均需"大幅度缩小"。

层级示例：

| 层级 | 级别 | 走势结构标注 | 背驰段 | 背驰判定依据 |
|---|---|---|---|---|
| 第一层 | 日线 | a+A+b+B+c | c 段 | c 与 b 比 MACD 绿柱面积 + 黄白线高度大幅缩小 |
| 第二层 | 30 分钟 | a1+A1+b1+B1+c1 | c1 段 | c1 与 b1 比 MACD 绿柱面积 + 黄白线高度大幅缩小 |
| 第三层 | 5 分钟 | a2+A2+b2+B2+c2 | c2 段 | c2 与 b2 比 MACD 绿柱面积 + 黄白线高度大幅缩小 |

（各级别背驰点完全重合，即区间套。）

### 6.5 买卖点区间（容错定位）

- 即使功力不够、无法精确定位到买卖点的具体价位，也能定位一个合理的**买卖点区间**。
- 精准第一类买点附近的小区间仍具买入价值（如精准点 4.13，4.2 买入仍有上涨空间）。
- 对初学者，能定位到一个可容忍的买卖点区间即已成功。

## 7. 背驰/盘背判断线段终结

> 本讲的核心论点：仅用特征序列分型判断线段终结，会**"快了半拍"**（即判定提前半拍，走势往往已经反向走了一段才被分型确认）。背驰/盘背是判断线段终结的利器，用来弥补特征序列分型"快了半拍"的缺陷，使线段终结的判定更敏锐、更可靠。

### 7.1 特征序列与分型回顾

- 线段至少由三笔构成，相邻两笔方向相反。
- 判断线段是否结束，需观察线段内反方向笔构成的特征序列：
  - 判断向上线段是否结束 → 该向上线段内的每一个**向下笔**的高低点作为特征序列元素；
  - 判断向下线段是否结束 → 该向下线段内的每一个**向上笔**的高低点作为特征序列元素。
- 对特征序列进行包含处理（处理半酣关系）后，像 K 线组合一样做分型识别：
  - **顶分型**：相邻三元素，中间元素的高点最高（第 i 元素高点 < 第 i+1 元素高点，且第 i+1 元素高点 > 第 i+2 元素高点）。
  - **底分型**：相邻三元素，中间元素的低点最低（第 i 元素低点 > 第 i+1 元素低点，且第 i+1 元素低点 < 第 i+2 元素低点）。
- 特征序列第一元素和第二元素不能做向左包含处理；顶或底两侧的特征序列不能随意包含处理。
- **第一特征序列**：线段未被确认终结前形成的特征序列。
- **第二特征序列**：线段疑似终结后、用以再次确认的特征序列。

### 7.2 特征序列分型的局限：快了半拍

- 用特征序列分型判断线段终结，会出现"快了半拍"的问题：分型确认线段终结时，实际走势往往已经反向走了一段。
- 也就是说，单凭特征序列分型，线段终结的确认滞后于力度衰减的实际发生点。
- 因此引入背驰/盘背作为力度层面的判定，与分型的结构层面判定结合，弥补这一时滞。

### 7.3 背驰/盘背在判断线段终结中的分工

- **背驰**：用于判断**趋势**线段的终结。趋势含两个及以上同级别中枢，出中枢段力度小于进中枢段即构成背驰，预示趋势线段终结。
- **盘背**：用于判断**盘整**线段的终结。盘整只有一个中枢，离开中枢段力度小于进入中枢段即构成盘背，预示盘整线段终结。
- 二者不可混用：趋势线段用背驰，盘整线段用盘背。

### 7.4 线段终结判定流程

1. 识别当前线段方向（向上/向下）。
2. 找出该线段内部的特征序列（反方向笔）。
3. 对特征序列进行包含处理（合并同向相邻元素，处理半酣关系），得到标准特征序列。
4. 在标准特征序列中寻找分型（顶分型/底分型）。
5. 判断线段所属走势类型，选择力度判定工具：
   - 趋势线段 → 用背驰；
   - 盘整线段 → 用盘背。
6. 检查最后一段同向推动是否出现背驰/盘背（MACD 面积 + 黄白线，见第 4 章）。
7. **分型确认 + 背驰/盘背确认 → 判定线段终结**。

### 7.5 分型与背驰/盘背的关系

- 分型是**结构**层面的判断，背驰/盘背是**力度**层面的判断，二者结合方可确认线段终结。
- 分型确认是必要条件：仅有背驰/盘背而无分型，不能判定线段终结。
- 背驰/盘背是更敏锐的力度信号，用来弥补特征序列分型"快了半拍"的时滞。
- 特征序列必须先做包含处理再做分型判断，否则会误判。
- 第二特征序列用于线段终结后的二次确认，避免过早判定终结。

### 7.6 与三类买卖点的关系

- **第一类买卖点**：线段终结点，由背驰/盘背确认。
  - 第一类买点：向下线段末端出现底背驰/盘背后的买入点；
  - 第一类卖点：向上线段末端出现顶背驰/盘背后的卖出点。
- **第二类买卖点**：第一类买卖点之后，首次反弹/回调不创新高/新低形成，依附于第一类买卖点存在。
- **第三类买卖点**：中枢上沿/下沿被突破后回抽不进中枢形成。常出现在线段终结后的新线段运行中。

## 8. 小级别背驰引发大级别转折（小转大）

### 8.1 标准背驰（对照基准）

以两中枢上涨趋势为例，标准背驰须满足：

- 必须走出 `a+A+b+B+c` 的结构；
- 其中 `c` 必须为次级别走势；
- `c` 内部必须符合区间套原则，即 `c` 内部也是背驰的；
- `c` 段为背驰段；`c` 段是次级别走势，内部包含两个次级别中枢；`c` 段内部顶背驰的位置与 `a+A+b+B+c` 上涨趋势顶背驰的位置完全重合。

### 8.2 小转大的定义

- **小转大**：在本级别 `a+A+b+B+c` 走势**没有出现背驰**的情况下，本级别走势在 `a+A+b+B+c` 的高点处发生转折。
- 即本级别走势并未走完、未出现本级别背驰，却在高点发生转折。

### 8.3 小转大的三种情况

需区分以下三种情况，按对应级别背驰处理：

1. `c` 段为次级别 30 分钟走势，`c` 段发生背驰，其后的向下是 30 分钟的反向走势 → 按 30 分钟级别背驰处理。
2. `c` 段为次级别 30 分钟走势，`c` 段没有发生背驰，是次级别以下级别（5 分钟或以下）发生背驰 → 按对应级别背驰处理。
3. `c` 段本身没有走完，是次级别以下走势（即 `c` 段是 30 分钟以下级别的走势），并发生次级别以下级别的背驰 → 按对应级别背驰处理。

### 8.4 应对措施与减仓规则

- 小转大是小概率事件，处理不了可直接放弃。
- 小转大一般出现在行情末尾（暴涨之后的回跌、暴跌之后的反弹）；震荡行情下不易出现。
- 实战减仓规则（以高点转折为例，严格按本级别操作）：
  - **第一次减仓位置（最优）**：从高点回跌下来第一段结束后的第一次反弹的高点。
  - **第二次减仓位置（次优）**：第一个小级别盘整走势的高点（即向下段结束后的向上段第一笔高点）。
  - 跌破本级别第一个中枢震荡的高点后，其后的反弹可清仓。
  - 本级别买点回补。
- 操作级别决定是否清仓：操作级别大则减仓即可，操作级别小则需清仓。

### 8.5 与走势终完美的关系

- 小转大导致的大级别转折并未违背"走势终完美"：
  - 小转大导致的大级别转折，也是由于小级别背驰后，低级别走势递归、升级，走出大级别走势类型，最终才导致的大级别转折。
- 即小转大并非"无背驰转折"，而是转折发生在更小级别，经递归传导至大级别。

| 特征序列 | 线段内反方向笔的高低点构成的序列 |
| 第一/第二特征序列 | 线段终结确认前/后的特征序列 |
| 区间套 | 各级别背驰点完全重合，逐级收敛定位买卖点 |
| 第一类买卖点 | 走势类型转换的转折点（背驰/盘背确认的线段终结点） |
| 第二类买卖点 | 第一类之后首次反弹/回调不创新高/新低形成 |
| 第三类买卖点 | 中枢上/下沿被突破后回抽不进中枢形成 |
| 小转大 | 本级别未背驰但发生转折（转折源自更小级别背驰） |

## 10. 给 AI 的实现要点清单

以下汇总所有数值判定、边界条件与特例，作为代码实现的核对清单：

### 10.1 中枢构造

- [ ] 中枢 = 连续 3 个次级别走势的重叠区间。
- [ ] 中枢上界 = 三段走势低点的最大值；中枢下界 = 三段走势高点的最小值；上界 ≥ 下界时中枢成立。
- [ ] 1 分钟为最低级别；1 分钟线段为 1 分钟中枢的最小构成元素。
- [ ] 递归：3 个 1min 走势重叠 → 5min 中枢；3 个 5min 走势重叠 → 30min 中枢；以此类推。
- [ ] 禁止第一笔就是中枢的起点（参考原文约束）。

### 10.2 中枢形态演变

- [ ] 新生：原中枢出现 3 买/卖 → 在上方/下方形成新同向中枢。
- [ ] 延伸：第 4~8 段次级别走势与中枢区间重合 → 仍为延伸/震荡。
- [ ] 扩展阈值：次级别累计达 **9 段** → 升级为高级别中枢（原中枢未结束、无 3 买）。
- [ ] 扩张：两个同向中枢的震荡区间重合 → 升级（原中枢已结束、有 3 买）。
- [ ] 扩展 vs 扩张判定：是否有 3 买、原中枢是否结束。

### 10.3 走势类型

- [ ] 上涨：≥2 个向上中枢；下跌：≥2 个向下中枢；盘整：有且仅有 1 个中枢。
- [ ] 走势终完美：走势必完成，完成后转换为其他类型。
- [ ] 六种组合分类；有买入价值组合：下跌+上涨、下跌+盘整+上涨、上涨+盘整+上涨。

### 10.4 背驰判定

- [ ] 前提：必须有中枢；无中枢不背驰。
- [ ] 出中枢笔必须真正突破中枢区间，否则不构成背驰判定对象。
- [ ] 比较对象：进中枢笔 vs 出中枢笔，必须同方向、同级别。
- [ ] 必须等笔走完后判定（未完成笔不判定）。
- [ ] 面积背驰：出中枢段 MACD 柱面积 < 进中枢段柱面积（上涨看红柱、下跌看绿柱）。
- [ ] 黄白线背驰：出中枢段黄白线高度/低度弱于进中枢段。
- [ ] 面积为主、黄白线辅助；两者一致更可靠。
- [ ] MACD 面积取值区间严格对应笔/段的起止点。
- [ ] 趋势背驰需 ≥2 同级别中枢；盘整背驰为 1 个中枢；无趋势时只能称盘背。
- [ ] 背驰段内部含中枢时逐级分析，不能跨级别套面积。

### 10.5 盘整背驰演化

- [ ] 标准结构 a+B+c，c 为背驰段，c 与 a 比 MACD。
- [ ] 盘背成立条件：柱面积缩小 或 黄白线降低（满足其一即可，两者同满足则更强）。
- [ ] 形态一：c 创新高 + 盘背 + 回拉不破中枢上限（3 买）→ 演化为趋势。
- [ ] 形态二：c 创新高 + 盘背 + 回跌破回中枢内 → 继续盘整。
- [ ] 形态三：c 未创新高 + 盘背 → 必有回跌，先减仓。
- [ ] 大周期无标准一买时，盘背低点当大周期一买、盘背高点当大周期一卖。

### 10.6 区间套

- [ ] 每层背驰段对应次级别仍为 a+A+b+B+c 或 a+A+b 同型结构。
- [ ] 各级别背驰点完全重合 → 构成区间套。
- [ ] 背驰判定：MACD 柱面积 + 黄白线高度均"大幅度缩小"。
- [ ] 逐级递归直至 1 分钟级别定位精确买卖点。
- [ ] 容错：定位买卖点区间而非精确点亦可。

### 10.7 线段终结

- [ ] 特征序列 = 线段内反方向笔的高低点。
- [ ] 特征序列先做包含处理（处理半酣关系）再做分型。
- [ ] 顶分型：中间元素高点最高；底分型：中间元素低点最低。
- [ ] 第一/第二特征序列区分（第二用于二次确认）。
- [ ] 仅用特征序列分型会"快了半拍"，必须结合背驰/盘背。
- [ ] 趋势线段用背驰判定终结；盘整线段用盘背判定终结（不可混用）。
- [ ] 线段终结 = 分型确认 + 背驰/盘背确认（二者缺一不可）。
- [ ] 仅有背驰/盘背无分型 → 不能判定终结。

### 10.8 小转大

- [ ] 小转大：本级别 a+A+b+B+c 未背驰但在高点转折。
- [ ] 三种情况按对应级别处理（c 段背驰级别 / 次级别以下背驰级别 / c 段未走完的更小级别背驰）。
- [ ] 减仓规则：第一次=回跌首段后反弹高点；第二次=首个小级别盘整高点；跌破首中枢震荡高点后反弹可清仓。
- [ ] 小转大不违背走势终完美（转折源自更小级别背驰递归传导）。
