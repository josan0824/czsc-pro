# 服务端部署说明

本文说明如何启动交互式缠论图表服务，并提供外部浏览器访问入口。

## 功能

- 首页默认加载 `SH000001` 上证指数。
- 支持快捷选择：
  - `SH000001`
  - `000001.SZ`
  - `000905.SH`
  - `SH000852`
  - `SH000300`
  - `SH000016`
  - `688111.SH`
  - `002475.SZ`
- 支持手动输入股票代码查询。
- 图表支持滚轮缩放、拖拽平移、双击十字星、悬停查看 OHLC。
- 服务端按请求实时拉取行情并生成 HTML 图表。
- 默认使用通达信 `mootdx` 数据源，页面也保留通达信本地历史数据和东方财富数据源作为可选项。

## 启动命令

本地访问：

```bash
/opt/homebrew/bin/python3.11 web_server.py --host 127.0.0.1 --port 8000
```

服务端外部访问：

```bash
/opt/homebrew/bin/python3.11 web_server.py --host 0.0.0.0 --port 8000
```

如果服务端 Python 路径不同，可替换为：

```bash
python3 web_server.py --host 0.0.0.0 --port 8000
```

## 访问地址

入口页：

```text
http://服务器IP:8000/
```

本机测试地址：

```text
http://127.0.0.1:8000/
```

单图表地址：

```text
http://服务器IP:8000/chart?code=SH000001&lv=1m&days=60&source=mootdx
```

参数说明：

| 参数 | 示例 | 说明 |
| --- | --- | --- |
| `code` | `SH000001` / `000001.SZ` | 股票或指数代码 |
| `lv` | `1m` / `5m` / `15m` / `30m` / `60m` / `day` | K 线级别 |
| `days` | `60` | 拉取最近多少天数据 |
| `source` | `mootdx` / `tdx_history` / `eastmoney` / `tqsdk` | 行情数据源，默认通达信 |

## 依赖

服务端入口使用 Python 标准库 `http.server`，不需要 Flask/FastAPI。

建议使用 Python 3.10 或 3.11。当前代码已兼容 Python 3.10；如果服务器报 `cannot import name 'Self' from 'typing'`，说明部署目录还是旧代码，需要重新同步最新的 `Combiner/KLine_Combiner.py`、`Seg/Eigen.py`、`Seg/Seg.py`。

行情数据默认使用项目已有的通达信数据源 `DATA_SRC.MOOTDX`。需要确保运行环境已安装项目依赖，至少包含：

```bash
pip install -r Script/requirements.txt
pip install mootdx
```

## 天勤数据源

页面中的“天勤”对应 `source=tqsdk`，只支持以下指数代码：

| 名称 | 天勤代码 |
| --- | --- |
| 上证50 | `SSE.000016` |
| 沪深300 | `SSE.000300` |
| 中证500 | `SSE.000905` |
| 中证1000 | `SSE.000852` |

启动服务前通过环境变量提供快期账户，凭据不写入代码或 URL：

```bash
export TQ_ACCOUNT="your-account"
export TQ_PASSWORD="your-password"
python web_server.py --host 127.0.0.1 --port 8000
```

天勤源每次使用 `get_kline_serial()` 请求最新向前的 10,000 根 K 线，无需专业版历史下载权限。该接口返回的序列会随行情更新；在非交易时段或账户未开通对应指数的分钟行情时，服务器可能不会返回分钟数据。

## 通达信本地历史数据

页面中的“通达信历史数据”对应 `source=tdx_history`。它优先读取本机或服务器上的历史文件；没有本地缓存时会尝试通过现有 `mootdx` 数据源补齐并写回缓存。命中导入的 CSV 快照时则保持离线读取。

启动服务前，设置 `TDX_HISTORY_DIR` 为包含 `vipdoc` 目录的通达信安装目录：

```bash
export TDX_HISTORY_DIR="/path/to/tdx"
/opt/homebrew/bin/python3.11 web_server.py --host 127.0.0.1 --port 8000
```

也可以在启动时直接传入目录：

```bash
/opt/homebrew/bin/python3.11 web_server.py --host 127.0.0.1 --port 8000 --tdx-history-dir "/path/to/tdx"
```

`TDX_HISTORY_DIR` 也可以直接指向 `vipdoc` 目录。需要先在通达信客户端中下载对应标的和周期的数据，文件路径示例：

```text
vipdoc/sh/minline/sh000001.lc1
vipdoc/sh/fzline/sh000001.lc5
vipdoc/sh/lday/sh000001.day
```

也支持导入按日拆分的 1 分钟 CSV 快照，目录和文件名需要保持下面的形式：

```text
data/tdx/vipdoc/2026-07_1min/20260701_1min/sh688136.csv
data/tdx/vipdoc/2026-07_1min/20260701_1min/sz000001.csv
```

CSV 使用 UTF-8 BOM 编码，至少需要 `datetime`、`open`、`high`、`low`、`close`、`volume`、`amount` 列。服务只读取当前请求代码对应的文件，不会扫描或加载整个月的全部股票文件；同一时间戳时，CSV 快照优先于 `.lc1` 缓存。请求范围与 CSV 快照有重叠时会离线出图，不等待在线通达信补齐；它可直接用于 1 分钟、5 分钟、15 分钟、30 分钟和 60 分钟图，其中后四个级别由 1 分钟数据聚合。

本地历史源原生读取 1 分钟、5 分钟和日线；15/30/60 分钟线由本地 1 分钟数据聚合，缺少 1 分钟文件时会尝试用 5 分钟数据聚合。该源使用通达信本地原始未复权数据。页面的“天数”仍表示从当前日期向前的滚动窗口；选择“全部”会读取文件中的所有记录。

## 部署注意

- 对外访问时必须使用 `--host 0.0.0.0`。
- 云服务器安全组或防火墙需要放行对应端口，例如 `8000`。
- 首页只是入口页，图表内容由 `/chart` 按请求实时生成，因此首次加载或切换代码时会等待行情接口返回。
- 当前服务不做鉴权；如果暴露到公网，建议放到 Nginx 后面并增加访问控制。
